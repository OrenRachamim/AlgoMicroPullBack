# אפיון מערכת התראות — אסטרטגיית הריטסט (SMA20 Retest)

> מסמך למודל שפה שיממש את מערכת ההתראות. גרסה 2 — האסטרטגיה הרשמית עודכנה
> לדפוס הריטסט לאחר סבב מחקר נוסף (ראו results/ITERATIONS.md). המערכת
> **מתריעה בלבד**: אין ביצוע עסקאות ואין מסחר תוך-יומי. אין לשנות פרמטרים
> בלי בדיקה חוזרת ב-backtest. מימוש ייחוס: `daily_scan.py` במאגר זה.

---

## 1. האסטרטגיה בקצרה (התקציר שמצורף לכל התראה)

> מניה שחצתה לאחרונה מעל כל הממוצעים הנעים אחרי חצי שנה מתחתיהם, חזרה לגעת
> ב-SMA20 כשהמבנה (SMA100/200) שלם. קונים בפריצת השיא של יום הנגיעה, מוכרים
> בסגירת היום העשירי. בלי סטופ מחיר — ההגנה היא גודל פוזיציה (20% מההון, עד
> ‏5 פוזיציות) וסטופ-זמן. ‏Backtest ‏2018–2026: ‏802 עסקאות, ‏53% הצלחה,
> ‏+0.21% לעסקה, ‏+28.2% סה"כ.

## 3. אינדיקטורים (על סגירה מתואמת; אין lookahead — תנאי יום t מנתוני t בלבד)

‏SMA10/20/50/100/200 (NaN עד חלון מלא) · ‏ret63 = ‏close/close[t-63]−1 ·
‏dollar_vol20 = ממוצע 20 ימים של close·volume · ‏MACD ‏(EMA12−EMA26) ·
‏RSI14 ‏(Wilder) · ‏ATR14 ‏(Wilder).

## 4. לוגיקת הסיגנל — "מועמדת ריטסט" בסגירת יום t

### 4.1 משטר שוק
```
SPY_close[t] > SMA200(SPY)[t]          # אם לא — אין התראות כניסה היום
```

### 4.2 חלון פריצה טרייה
```
above_all[d] = close[d] > SMA10,SMA20,SMA50,SMA100,SMA200 (כולם)
cross[d]     = above_all[d] AND sum(above_all[d-126..d-1]) <= 5 AND SMA200 valid
in_window[t] = קיים cross ב-60 ימי המסחר האחרונים
```

### 4.3 שערי מגמה והיגיינה (ביום t)
```
close > SMA50            # מבנה בינוני
MACD > 0 ;  ret63 > 0    # משטר ומומנטום חיוביים
ATR14/close <= 0.04      # לא מניה מתפרקת
close >= 5$ ;  dollar_vol20 >= 20M$
```
(הערה: שער ה-RSI14 כבוי בדפוס זה — ‏require_rsi14_min=0.)

### 4.4 הריטסט (הטריגר)
```
low[t]  <= SMA20[t] * 1.01      # נגיעה בקו (±1%)
close[t] > SMA50[t] * 0.99      # הנגיעה לא שברה את המבנה הקצר
close[t] > SMA100[t]            # רצפת מבנה — חובה
close[t] > SMA200[t]            # רצפת מבנה — חובה
```

### 4.5 פילטר דוחות
```
t+1 וגם t+2 אינם ימי-דוח (risk day = יום המסחר הראשון >= תאריך הדיווח)
```

### 4.6 ההוראה שנשלחת
```
BUY-STOP מחר:  trigger = high[t] * 1.001
אם לא נפרץ מחר — הסטאפ ממשיך להתעדכן (נגיעה חוזרת מייצרת סיגנל חדש).
יציאה: בסגירת יום המסחר ה-10 מהכניסה. אין סטופ מחיר. אין trailing.
דירוג כשיש יותר מ-5 מועמדות: ret63 יורד. גודל פוזיציה: 20% מההון.
```

## 5. ההתראות

### 5.1 יומית — אחרי הסגירה (16:45 ET, ימי מסחר בלבד)
רשימת כל המועמדות + תקציר האסטרטגיה (סעיף 1). נשלחת **גם כשאין מועמדות**
(שורת "אין היום") וגם כש-SPY מתחת ל-SMA200 ("אין כניסות — משטר שלילי").
פורמט ההודעה: ראו `format_message` ב-`daily_scan.py`. ‏JSON נשמר ללוג.

### 5.2 ערוצי שליחה
| ערוץ | מימוש | קונפיגורציה (env) |
|---|---|---|
| Telegram | ‏Bot API: ‏`api.telegram.org/bot{token}/sendMessage` | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Email | ‏SMTP + STARTTLS (‏Gmail: ‏smtp.gmail.com עם App Password) | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `ALERT_EMAIL_TO` |

חסר credentials ← מדלגים על הערוץ ומדווחים, לא נכשלים. כשל שליחה ← ‏retry
אחד אחרי 60 שניות, ואז לוג שגיאה.

### 5.3 התראות יציאה (לפוזיציות שהמשתמש מנהל ברשימה)
לכל פוזיציה פתוחה, בסגירת כל יום:
```
1. דוח ביום המסחר הבא  → "מכור היום בסגירה" (יציאה כפויה לפני דוח)
2. חלפו 10 ימי מסחר    → "מכור היום בסגירה" (סטופ-זמן)
```
**אין שום התראת סטופ-מחיר.** נבדקו שישה סוגים (ATR, אחוז, trailing, ‏EMA10,
‏SMA20 בכל עומק, ‏SMA50) — כולם הרעו. ירידה מתחת ל-SMA20 אחרי כניסה היא
חלק מהמסלול הנורמלי (73% מהריטסטים נבעטים חזרה) ואינה אירוע.

## 6. דרישות מימוש
‏idempotency ‏(מפתח: scan_date) · לוח מסחר NYSE · ולידציית נתונים (נר חסר ←
דילוג+אזהרה; ‏SPY חסר ← התראת תקלה) · קובץ קונפיג לכל הקבועים · לוג יומי מלא.

## 7. בדיקות קבלה
1. אינדיקטורים ואי-lookahead (כמו בגרסה 1).
2. סינתטי: בסיס ארוך מתחת לממוצעים ← חצייה ← ראלי ← נגיעה ב-SMA20 מעל
   ‏SMA100/200 ← מועמדת; אותה נגיעה עם סגירה מתחת ל-SMA100 ← לא; מניה
   שמעל הממוצעים שנתיים (בלי חצייה טרייה) ← לא.
3. דוח מחר ← המועמדת נפסלת; לפוזיציה פתוחה ← התראת מכירה היום.
4. רגרסיה מול ה-backtest: ‏SLB חייבת להיות מועמדת בסגירת ‏29.12.2025
   (כניסה בפועל 30.12 ב-37.56$); ‏CDNS בסגירת ‏19.5.2026.
5. שליחה: ‏mock לשני הערוצים; ודא שההודעה כוללת את תקציר האסטרטגיה.

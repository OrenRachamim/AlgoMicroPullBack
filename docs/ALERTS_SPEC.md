# אפיון מערכת התראות — אסטרטגיית Micro Pullback על פריצה טרייה

> מסמך זה מיועד למודל שפה שיכתוב את קוד המערכת. הוא מגדיר **מערכת התראות בלבד**:
> איתור הימים הרלוונטיים (סיגנלים לכניסה והתראות יציאה). אין בו לוגיקת מסחר
> תוך-יומי, ניהול הזמנות או חיבור לברוקר. כל הפרמטרים נקבעו ב-backtest על
> 590 מניות (2023–2026) ואומתו על 2018–2021 — אין לשנות ערכים בלי בדיקה חוזרת.

---

## 1. מטרת המערכת

לזהות מדי יום:
1. **מועמדי כניסה** — מניות שסיימו היום "מיקרו-פולבק" (נסיגה קצרה וחדה) בתוך
   "חלון פריצה טרייה" (עלייה ראשונה מעל כל הממוצעים הנעים אחרי תקופה ארוכה
   מתחתיהם). אלו הימים שבהם, סטטיסטית, יום המחרת ירוק בהסתברות ~53-54%
   והבאונס בחמשת הימים הבאים ממוצע ‏+0.5%.
2. **התראות יציאה** — לפוזיציות פתוחות: מימוש חוזק, סטופ-זמן, ודוח מתקרב.

ההתראות נשלחות בשני מועדים: **אחרי סגירת המסחר** (הסריקה הראשית) ו**לפני
הפתיחה** (אימות בוקר).

---

## 2. נתונים נדרשים

### 2.1 נתוני מחיר יומיים
- OHLCV יומי **מתואם** (splits + dividends) לכל מניית יוניברס + SPY.
- מקור עובד ללא מפתח: Yahoo Finance chart API —
  `GET https://query1.finance.yahoo.com/v8/finance/chart/{ticker}?period1={epoch}&period2={epoch}&interval=1d&events=div,splits&includeAdjustedClose=true`
  עם `User-Agent` של דפדפן. יש להכפיל את ה-OHLC בפקטור `adjclose/close`.
- **עומק היסטוריה מינימלי: 700 ימים קלנדריים** לפני היום הנסרק (נדרש
  ל-SMA200 + זיהוי החצייה שדורש 126 ימי עבר נוספים).
- Cache מקומי; עדכון יומי של הנר האחרון בלבד.

### 2.2 יוניברס
- ברירת מחדל: ~600 מניות ה-mega/large-cap מ-NASDAQ screener —
  `GET https://api.nasdaq.com/api/screener/stocks?tableonly=true&limit=1500&marketcap=mega|large`
  (עם User-Agent דפדפן), מיון לפי שווי שוק, סינון לסימבולים `^[A-Z]{1,5}$`.
- רענון היוניברס: פעם בשבוע. מניה שיצאה מהיוניברס אך מוחזקת — ממשיכים לעקוב.

### 2.3 תאריכי דוחות (earnings)
- מקור היסטורי+עתידי חינמי: SEC EDGAR.
  - מיפוי טיקר←CIK: `https://www.sec.gov/files/company_tickers.json`
  - הגשות: `https://data.sec.gov/submissions/CIK{cik:010d}.json` —
    לסנן `form == "8-K"` עם `items` המכיל `"2.02"`. תאריך ההגשה ≈ יום ההכרזה.
  - חובה `User-Agent` עם פרטי קשר; ≤10 בקשות/שנייה.
- **ללוח צופה-קדימה** (דוח שטרם הוגש): להצליב עם
  `https://api.nasdaq.com/api/calendar/earnings?date=YYYY-MM-DD` או נתוני
  הברוקר. מניה ללא מידע דוחות (מנפיק זר, 6-K) — הפילטר לא פעיל לגביה ויש
  לסמן זאת בהתראה (`earnings_data: "unavailable"`).

## 3. אינדיקטורים (חישוב על סדרת הסגירה המתואמת)

| אינדיקטור | הגדרה מדויקת |
|---|---|
| SMA10/20/50/100/200 | ממוצע נע פשוט; `NaN` עד שיש חלון מלא |
| EMA20 | `ewm(span=20, adjust=False)`, ‏`NaN` עד 20 תצפיות |
| RSI2, RSI14 | **נוסחת Wilder**: ‏avg gain/loss עם `ewm(alpha=1/period, adjust=False)` |
| MACD | ‏EMA12 − EMA26 (קו ה-MACD בלבד; אין צורך בקו סיגנל) |
| ATR14 | ‏True Range עם החלקת Wilder ‏(`ewm(alpha=1/14)`) |
| hi20 | מקסימום סגירות 20 ימים, **מוזז יום אחד אחורה** (לא כולל היום) |
| support20 | מינימום lows ‏20 ימים, מוזז יום אחד אחורה |
| ret63 | ‏`close/close.shift(63) - 1` (מומנטום ~3 חודשים) |
| dollar_vol20 | ממוצע 20 ימים של `close*volume` |
| down_days | מספר ימי ירידה רצופים בסגירה, נכון להיום |

**כלל ברזל נגד lookahead:** כל תנאי מחושב מנתוני הסגירה של יום t בלבד.
הסיגנל של יום t מכוון לפעולה ביום t+1.

---

## 4. לוגיקת הסיגנל — "מועמד כניסה"

מניה היא מועמדת כניסה בסגירת יום t אם **כל** התנאים הבאים מתקיימים:

### 4.1 משטר שוק (תנאי גלובלי)
```
SPY_close[t-1] > SMA200(SPY)[t-1]        # ערכי אתמול — אין lookahead
```
אם לא מתקיים — אין שום התראות כניסה היום (יציאות כן נשלחות).

### 4.2 חלון פריצה טרייה (eligibility)
```
above_all[d] = close[d] > SMA10[d] AND > SMA20[d] AND > SMA50[d]
               AND > SMA100[d] AND > SMA200[d]

# יום חצייה מזכה:
cross[d] = above_all[d]
           AND sum(above_all[d-126 .. d-1]) <= 5     # כמעט לא היה מעל, חצי שנה
           AND SMA200[d] is not NaN

# המניה בחלון אם היה cross מזכה ב-60 ימי המסחר האחרונים:
in_fresh_window[t] = any(cross[t-59 .. t])
```

### 4.3 שערי מגמה והיגיינה (ביום t)
```
close[t] > SMA50[t]
MACD[t] > 0
RSI14[t] >= 40
ret63[t] > 0                      # מומנטום חיובי
ATR14[t] / close[t] <= 0.04       # לא מניה בהתפרקות
close[t] >= 5.0
dollar_vol20[t] >= 20_000_000
```

### 4.4 המיקרו-פולבק (הטריגר, ביום t)
```
RSI2[t] < 10                                  # פאניקה קצרה
down_days[t] >= 1                             # לפחות יום אדום אחד
0.01 <= 1 - close[t]/hi20[t] <= 0.07          # ‏1%–7% מתחת לשיא 20 יום
close[t] > support20[t]                       # מעל תמיכה
close[t] >= EMA20[t] * 0.97                   # לא יותר מ-3% מתחת ל-EMA20
```

### 4.5 פילטר דוחות
```
# risk_day(ticker) = יום המסחר הראשון שהוא >= תאריך דוח (מוכרז או צפוי)
t+1 is NOT a risk day     # יום הכניסה המיועד
t+2 is NOT a risk day     # הפוזיציה מוחזקת לפחות לילה
```

### 4.6 דירוג
כשיש יותר מועמדים ממקומות פנויים (ברירת מחדל: עד **5 פוזיציות** במקביל,
‏20% הון לפוזיציה): ממיינים את המועמדים לפי `ret63` **יורד** ולוקחים את
העליונים.

## 5. ההתראות

### 5.1 התראת ערב (26–60 דקות אחרי הסגירה, אחרי שנתוני EOD זמינים)
לכל מועמד שעבר את 4.1–4.6:
```json
{
  "type": "entry_candidate",
  "ticker": "GMAB",
  "signal_date": "2026-09-10",
  "action": "BUY at next market open",
  "close": 32.23,
  "rsi2": 3.6,
  "pct_below_20d_high": 6.3,
  "days_since_cross": 25,
  "ret63_pct": 32.0,
  "rank": 1,
  "next_earnings": "2026-11-05",
  "earnings_data": "ok",
  "planned_exit": "close when RSI2 > 65, OR at close of 5th trading day"
}
```

### 5.2 אימות בוקר (כ-5 דקות לפני הפתיחה)
לכל מועמד מאתמול:
- בדיקת דוחות חוזרת מול לוח צופה-קדימה (דוח שהתפרסם בלילה ← ביטול התראה).
- דיווח כיוון הגאפ מול סגירת אתמול: ‏gap-up מעלה מעט את ההסתברות ליום ירוק
  (54.3% מול 52.2%). **מידע בלבד — לא תנאי ביטול.**
```json
{ "type": "morning_check", "ticker": "GMAB", "status": "confirmed",
  "gap_pct": +0.4, "note": "gap-up: היסטורית P(יום ירוק)=54.3%" }
```

### 5.3 התראות יציאה (בודקים בסגירת כל יום, לכל פוזיציה פתוחה)
המערכת מחזיקה רשימת פוזיציות (ticker, entry_date, entry_price) שהמשתמש מעדכן.
סדר בדיקה:
```
1. earnings:  יום המסחר הבא הוא risk_day        → "SELL at close today" (לפני הדוח)
2. strength:  RSI2[today] > 65                  → "SELL at close" (מימוש הבאונס)
3. time:      today >= entry_date + 5 ימי מסחר  → "SELL at close" (סטופ-זמן)
```
אין סטופ מחיר ואין trailing — נבדקו והרעו את התוצאות. אין לממש.

### 5.4 התראה שבועית — watchlist
רשימת כל המניות שכרגע `in_fresh_window` (עם ימים שנותרו בחלון) — אלו
המניות שמהן יגיעו הסיגנלים הקרובים.

## 6. דרישות מימוש

1. **תזמון**: ‏cron — סריקת ערב ‏16:45 ET, אימות בוקר ‏09:25 ET, ‏watchlist
   ראשון בערב. התחשבות בימי מסחר בלבד (לוח NYSE).
2. **Idempotency**: הרצה כפולה של אותו יום לא שולחת התראה כפולה
   (מפתח: `type+ticker+signal_date`).
3. **ולידציית נתונים**: נר חסר/אפס-ווליום/מחיר שלילי ← דילוג על המניה היום
   ורישום אזהרה. אם SPY חסר ← אין סריקה, התראת תקלה.
4. **ללא lookahead**: אסור להשתמש בנתון כלשהו של יום t+1 בחישוב סיגנל של t.
5. **ערוצי התראה**: מופשט (interface) — מימוש ראשון: email/Telegram/console.
6. **קובץ קונפיגורציה** עם כל הקבועים מסעיפים 3–5 (ערכי ברירת מחדל כנ"ל).
7. **לוג יומי** של כל ההחלטות (גם "אין מועמדים") לצורכי ביקורת.

## 7. בדיקות קבלה (חובה לממש)

1. **אינדיקטורים**: ‏RSI Wilder — סדרה עולה מונוטונית ← RSI→100; לרדת ← →0.
2. **ללא lookahead**: חיתוך הסדרה ב-60 הנקודות הראשונות נותן ערכים זהים
   לחישוב על הסדרה המלאה באותן נקודות.
3. **חצייה מזכה**: סדרה סינתטית — ‏300 ימים מתחת לממוצעים, עלייה מעליהם ←
   ‏cross ביום הנכון; מניה שמעל הממוצעים שנתיים ← אף פעם לא בחלון.
4. **סיגנל מלא**: מגמת עלייה סינתטית + דיפ של 3 ימים (-3.5%) ← מועמד;
   דיפ של 12% ← לא מועמד; אותו דיפ בלי חצייה טרייה ← לא מועמד.
5. **דוחות**: דוח מחר ← המועמד נפסל והפוזיציה מקבלת התראת מכירה היום.
6. **רגרסיה היסטורית** (אם יש גישה לנתונים): ‏GMAB ב-10.9.2026 חייב לצאת
   מועמד; ‏DHR ב-1.10.2026 חייב לצאת מועמד.

## 8. מה מחוץ לתחולה (Scope)
- אין ביצוע עסקאות, אין חיבור לברוקר, אין ניהול הזמנות.
- אין לוגיקת מסחר תוך-יומי (תוספת עתידית: קטיפת יום ירוק עם fallback).
- אין את מודול ה-retake (כניסה בפריצת שיא + החזקת חודש) — תוספת עתידית.

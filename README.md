# AlgoMicroPullBack — מערכת מסחר Micro Pullback

מערכת backtesting לאסטרטגיית **micro pullback** במניות: איתור מניות חזקות
במגמת עלייה שירדו מעט (1–7%, ימים בודדים) וקנייה לקראת החזרה לעלייה,
עם החזקה של ימים בודדים. משתמשת ב-RSI, ‏MACD, ממוצעים נעים, ‏ATR,
רמות תמיכה/התנגדות ופילטר משטר שוק.

## האסטרטגיה הרשמית (`final`) — דפוס הריטסט (SMA20 Retest)

**עודכן (סבב 4):** הרשמית היא דפוס הריטסט — חצייה טרייה מעל כל הממוצעים ←
ראלי ← נגיעה ב-SMA20 כשהמבנה (SMA100/200) שלם ← קנייה בפריצת שיא יום
הנגיעה ← יציאה בסגירת היום ה-10. **ללא סטופ מחיר** (שישה סוגים נבדקו וכולם
הרעו). ‏2018–2026: ‏802 עסקאות, ‏+28.2%, ‏53% הצלחה. פירוט מלא:
`docs/ALERTS_SPEC.md`. סורק יומי עם שליחה לטלגרם/מייל: `daily_scan.py`.
האסטרטגיה הקודמת (דיפ עמוק) זמינה כווריאנט `dip`.

## האסטרטגיה הקודמת — Micro Pullback על פריצה טרייה

**הרעיון:** לא כל מניה במגמת עלייה — אלא רק מניות ש**זה עתה פרצו** מעל כל
הממוצעים הנעים אחרי תקופת התכנסות ארוכה מתחתיהם: תחילתה של מגמה חדשה.
על אלו קונים את הנסיגות הקצרות הראשונות.

**תנאי הכשירות (משטר הפריצה הטרייה):**
- המניה חצתה מעל **כל** הממוצעים SMA10/20/50/100/200 (כל הקווים מתחת למחיר)
- החצייה קרתה ב-**60 ימי המסחר האחרונים**
- לפני החצייה: לפחות **6 חודשים (126 ימי מסחר)** שבהם המניה כמעט ולא הייתה
  מעל כולם (עד 5 ימים חריגים)
- מומנטום חיובי (תשואת 63 ימים > 0), ‏MACD חיובי, ‏RSI14 ≥ 40

**תנאי הפולבק (הטריגר):**
- ‏RSI2 < 10 (נסיגה קצרה חדה), לפחות יום ירידה אחד
- ‏1%–7% מתחת לשיא 20 הימים; מעל תמיכת 20 יום; עד 3% מתחת ל-EMA20
- ‏ATR14/מחיר ≤ 4% (בלי מניות בהתרסקות), נזילות ≥ 20M$/יום

**כניסה:** למחרת בפתיחה, רק כש-SPY מעל SMA200, ולא כשהיום או המחר הם יום
דוח. עד 5 פוזיציות שוות-משקל, מועמדים מדורגים לפי מומנטום.

**יציאה** (אחרי מחקר יציאות ייעודי — ‏27 וריאנטים ב-4 סבבים):
‏**RSI2 > 65 בסגירה או אחרי 5 ימי מסחר**, ויציאה כפויה בסגירה שלפני יום
דוח. ללא סטופ מחיר וללא trailing — נבדקו trailing ATR/אחוזים, breakeven,
יציאת EMA10 ויעדי רווח; כולם הרעו את התוצאות במערכת mean-reversion קצרה
(נועלים את תחתית ה-V). מנגנונים אלה נשארים ממומשים וניתנים להפעלה דרך
`StrategyParams`.

**דילוג על דוחות (earnings):** תאריכי דוחות היסטוריים נשאבים מ-SEC EDGAR
(דיווחי 8-K עם Item 2.02) עם cache מקומי. אין כניסה ביום הדיווח או יום
לפניו, ופוזיציה פתוחה נסגרת בסגירת היום שלפני הדיווח — כך לא מחזיקים דרך
גאפ דוחות. בזמן אמת יש לבצע את אותה בדיקה מול לוח דוחות צופה-קדימה
(SEC, ‏API של NASDAQ, או נתוני הברוקר).

**תצורות נוספות:** ‏`leaders` — התצורה הקודמת (מובילות מומנטום ≥20% ללא
דרישת פריצה טרייה), נשמרת להשוואה; ‏`f5` — הגרסה השמרנית של השיטה החדשה
(גם מומנטום ≥10%): פחות עסקאות, איכות גבוהה יותר.

## תוצאות השיטה החדשה (יוניברס רחב ~590 מניות, 10.2023–10.2026, עמלות 20bps)

| תצורה | עסקאות | תשואה | CAGR | Sharpe | Max DD | Win % | PF |
|---|---|---|---|---|---|---|---|
| **final (פריצה טרייה)** | 294 | **+32.2%** | 9.8% | 1.16 | **-8.1%** | 66.3% | 1.49 |
| f5 (שמרנית, מומנטום ≥10%) | 193 | +28.4% | 8.8% | **1.41** | **-6.8%** | 67.9% | **1.78** |
| leaders (התצורה הישנה) | 623 | +62.3% | 17.7% | 1.17 | -19.3% | 63.6% | 1.35 |

השיטה החדשה מניבה פחות תשואה אבסולוטית מ-leaders אך עם **פחות ממחצית
ה-drawdown**, אחוז הצלחה גבוה יותר ו-PF טוב יותר. פרטי המחקר המלאים,
כולל תקופות קודמות של התצורה הישנה, ב-`results/ITERATIONS.md`.

## התקנה והרצה

```bash
pip install -r requirements.txt

# בדיקות
python -m pytest tests/ -q

# backtest של האסטרטגיה הרשמית (פריצה טרייה) על היוניברס הרחב
python run_backtest.py --universe broad --start 2023-10-19 --end 2026-10-19 \
    --variant final --max-positions 5 --regime spy200 --rank momentum \
    --capital 10000 --save my_run

# השוואת וריאנטים (למשל וריאנטי היציאה)
python run_sweep.py --universe full --start 2022-01-01 --end 2025-08-01 \
    --variants e0,e19,e22 --regime spy200 --rank momentum --max-positions 5

# כיבוי פילטר הדוחות או שינוי חלון הסיכון
python run_backtest.py ... --no-earnings-filter
python run_backtest.py ... --earn-before 1 --earn-after 1
```

הנתונים יורדים מ-Yahoo Finance (ללא API key) ונשמרים ב-`data_cache/`
כך שריצות חוזרות מהירות.

## מבנה הפרויקט

```
micro_pullback/
  data.py        # הורדת נתונים יומיים + cache
  earnings.py    # תאריכי דוחות מ-SEC EDGAR (8-K Item 2.02) + חלונות סיכון
  indicators.py  # RSI, MACD, SMA/EMA, ATR, תמיכה/התנגדות, מומנטום
  strategy.py    # הגדרת ה-setup, טריגר כניסה, חוקי יציאה (StrategyParams)
  backtest.py    # מנוע backtest תיקי יומי (ללא lookahead) + מדדים
  variants.py    # וריאנטים: v1..v31, יציאות e0..e27, פריצות f1..f5, leaders, final
  universe.py    # רשימות מניות (קטן/מורחב/נאסד"ק/מלא)
run_backtest.py  # הרצת וריאנט יחיד + שמירת עסקאות ועקומת הון
run_sweep.py     # השוואת וריאנטים בטבלה
tests/           # 34 בדיקות יחידה (אינדיקטורים, אסטרטגיה, מנוע, דוחות, יציאות)
results/         # תוצאות ויומן איטרציות
```

## מודל הביצוע (ללא lookahead)

- ‏setup מחושב על נתוני סגירת יום t; הכניסה ביום t+1
- פילטר המשטר משתמש בערך של אתמול
- יציאות חוזק/זמן בסגירה; סטופים (אם מוגדרים) תוך-יומיים עם מודל גאפים
- עמלה + slippage: ‏10bps לכל צד

## אזהרה

זהו כלי מחקר. ביצועי עבר אינם ערובה לביצועים עתידיים. היוניברס הסטטי יוצר
survivorship bias שמנפח תוצאות. אין לראות בזה ייעוץ השקעות.
